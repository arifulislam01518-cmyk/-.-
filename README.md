## আপডেট (v2)

- বার্ষিক
- প্রাক নির্বাচনি
- নির্বাচনি

### আইডি সিস্টেম
- রোলের বদলে **আইডি নম্বর** প্রাধান্য (PDF ট্রান্সক্রিপ্ট অনুসারে)
- রোল ঐচ্ছিক রাখা হয়েছে
- ফলাফল খোঁজা যায় আইডি **অথবা** রোল দিয়ে

### Academic Transcript (PDF স্টাইল)
ফলাফল দেখালে দেখাবে:
- মাদরাসার নাম, ঠিকানা, Email, লোগো
- Roll, ID, Name, Father, Class
- Total Marks, Average %, GPA, Grade, Result, Merit Position
- Subject-wise table (Sl, Subject, Full, Obtained, %)
- Remarks + Signature of Super / Asst. Super / Class Teacher

### Excel ইমপোর্ট
স্যাম্পল ডাউনলোড করে ফরম্যাট দেখুন। PDF-এর মতো English কলামও সাপোর্ট করে:
`Student's Name, Father's Name, Class, ID, Roll Number, Examination, Merit Position, Subject Name, Full Marks, Marks Obtained, Remarks`
